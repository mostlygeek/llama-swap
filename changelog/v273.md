## v273 (Nov 15, 2026)

A new `fit` selector strategy for capacity-aware model selection, some UI polish and a fix for the failing Docker builds.

Ohh! A new type of selector that allows loading variations of a model that best
fits in the currently available resources. Sometimes the full fat version of a
model isn't the right choice and you want a smaller version, perhaps with less
context or a lower quant. The new "fit" selector combined with the capacity
router to the rescue! Now llama-swap can choose a variation that can fit in the
currently available resources to serve the request. Thanks to @GitEventhandler
for the feature request!

This release also includes some UI changes:

- Support pasting of images into the Playground chat, thanks @kaczy44
- Improvements to the capture view to split the summary, request and responses. Less scrolling yay.
- Activity token counts adapt to screen size. Great for users who have send more than a hundred million tokens through llama-swap!

Also some docker container build changes. Thanks Opus, you're a better SRE than I ever was!
