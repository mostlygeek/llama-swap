## v275 (Nov 20, 2026)

Default Playground's Chat to not send params.

This is a tiny change to the UI but a giant leap getting
the repo ready for homebrew.

----

- [PR #1360](https://github.com/mostlygeek/llama-swap/pull/1360) ui/playground: disable chat parameters by default: starts the per-parameter enable checkboxes (temperature, top P, min P, top K, max tokens) switched off so a fresh Playground sends no sampler overrides and the engine's own defaults apply, because always overriding them broke engines with stricter ranges such as ninfer, which rejects `top_k` values above 20; previously saved choices are untouched by [@mostlygeek](https://github.com/mostlygeek)
- [PR #1361](https://github.com/mostlygeek/llama-swap/pull/1361) Makefile: build from a release tarball without git: lets packagers such as Homebrew build from GitHub's release tarball, which has no `.git` directory, by adding a `.git-commit` file that `git archive` fills with the commit hash (`export-subst` in `.gitattributes`) for `GIT_HASH`, and by making `make src` fall back to `find` (selecting the same files as `git ls-files`) so embedded source still works by [@mostlygeek](https://github.com/mostlygeek)
